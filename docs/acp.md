# ACP Sessions

Create a Session with an enabled ACP Agent from the Dashboard's client selector.

Press Enter to send a follow-up to the current task when the Agent offers steering. Otherwise, the message waits in Inbox until the task finishes. Tab or Alt+Enter always queues the message for after the current task.

When the Agent provides model choices, enter `/model` in the message composer to open the model picker and switch models in the same conversation. The picker shows the Agent's available models and confirmed current selection. Model choices and the current selection refresh when the Agent changes them or the Session reconnects.
