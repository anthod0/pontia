# @pontia/claude-client

Connect Claude Code to [Pontia](https://pontia.dev/) through the Claude Agent SDK. You can start Claude Code sessions on your device, follow their work, answer tool requests, and resume conversations from the Pontia Dashboard.

## Requirements

- Node.js LTS
- Claude Code credentials or a configured model provider
- Pontia running on the same device

## Install

Select **Claude Code** during `pontia init`, or install and enable the integration later:

```sh
pontia setup claude
```

Pontia installs this package and its Claude Agent SDK dependencies in a managed location.

For setup, authentication, custom configuration paths, and updates, see the [Claude Code Agent Client guide](https://pontia.dev/docs/agent-clients/claude).
